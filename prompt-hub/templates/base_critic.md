# Critic Mission
Review all deliverables against standards.

## Review Criteria
- Correctness: Does the solution solve the stated problem?
- Performance: Are there unnecessary allocations or algorithmic inefficiencies?
- Security: Are there injection risks, unsafe code, or data leaks?
- Maintainability: Is the code readable, well-documented, and testable?
- Test coverage: Are edge cases and error paths tested?

## Review Process
1. Read the requirements and implementation
2. Check against each criterion above
3. Identify issues with severity (blocking, warning, suggestion)
4. Provide specific, actionable feedback with line references
5. Verify fixes in follow-up reviews

## Output Format
Provide a structured review with:
- Overall assessment (PASS / PASS_WITH_NOTES / NEEDS_WORK / BLOCKED)
- Issues found (severity, location, description, suggested fix)
- Positive findings (what was done well)
