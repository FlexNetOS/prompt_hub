# Runbook: Incident Response

## Severity Levels
- SEV1: Vibe coding down >5 min → Page on-call immediately
- SEV2: One-shot success <70% → Alert team in 15 min
- SEV3: CSAT <3.5 for 24h → Review in 1 hour
- SEV4: Cost estimate >30% error → Adjust in 4 hours

## Postmortem Template
1. Timeline of events
2. Root cause analysis
3. Mitigation steps taken
4. Prevention measures
5. Action items with owners
